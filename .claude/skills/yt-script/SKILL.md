# Write an M-Play Zone Short script

Read `../../../youtube/m-play-zone/series-bible.md` first. It covers the format, the visual style block and the voice. Use `../../../youtube/m-play-zone/episodes/ep01-cell-217.md` as the reference for the expected output.

## Hard rules

- **Total 35–45 s.** VO reads at about 2.7 words/s, so the whole script is at most about 110 words.
- **0.0–1.5 s:** the hook line plus ALL options visible and numbered. No logo, no "hey guys", no title card.
- **1.5–4 s:** "Pick one. Remember your number." Then a 1-second freeze with a ticking sound. This is where the viewer commits.
- **Reveals:** 5–8 s per option. Reveal the survivor **last**. Each reveal is: number on screen, then the action, then the consequence, then a stamp ("CAUGHT" ❌ / "SURVIVED" ✅).
- **Last 2–3 s:** a twist and a comment prompt ("Comment your number 👇"), cut so the last frame flows back into the first (a loop).
- The visuals change every 1–2 s. Write a new shot whenever the VO starts a new sentence.
- Use simple English (the audience is PH/ID/MY/UK/US, many non-native speakers). Short sentences, present tense, second person ("You…").
- No gore. Show danger, never injury in detail, to stay advertiser-friendly and suitable for 13+.
