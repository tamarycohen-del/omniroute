# In This Town — Pirate Token (re-animated)

New 3D animation for the existing "In This Town Everyone Is Searching For The Pirate Token" short.
The original audio track is kept unchanged; every shot is timed to the narration's word timings.

- `pirate.html` — full self-contained scene (three.js 0.160, 1080x1920, 24 fps, `renderFrame(f)`).
- `pirate_core.txt` + `pirate_body.js` + `build_pirate.py` — sources; run `python3 build_pirate.py` to rebuild `pirate.html`.
- `words.json` — word timings from the original audio (faster-whisper).

32 shots: night town with moon, treasure chests, the W Chews restaurant, narrator in the black hoodie,
the wooden guy and his job application, the kid with glasses, the richest hunter (red camo cap, headphones),
the calculator "1 in 137500", the 300-person town square, golden avatars, and the noob who finds the token.
